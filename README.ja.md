**真・三國無双7 Empires**(Steam 版)の非公式 mod です。`dinput8.dll` 1つで動き、[`version.ini`](https://steamcommunity.com/profiles/76561198400651705) で設定します。ゲーム本来の不具合を直したり、クラッシュを防いだりします。戦いのバランスや AI の動き、画面の配置も調整できます。プレイヤーの操作を AI に任せる「オートバトル」もあります。

このファイルをダウンロードすると、Windowsがウイルスとして検出する場合がありますが、これは誤検出です。Windows Defenderのファイルを許可してくださいgithubにてオープンソースにしてあり,悪意のないコードを使ってmodを作っています overmase-AI-V~.exeは357E Editorで作成したパッチファイルです、これもウイルスとして誤検知される可能性があります、ツール元のファイルと357E Editorのソースはこちらです https://www.downxia.com/downinfo/382042.html

前回の公開からの変更は [RELEASE_NOTES.ja.md](RELEASE_NOTES.ja.md) を見てください。

## 対応している版

DLL が `Launch.exe` の作成日時の印を見て、版に合った場所を自動で使います。1つの `dinput8.dll` と `version.ini` で3つの版に対応しています。

| 版 | Launch.exe の作成日時の印 |
|---|---|
| 日本語版 1.0.5.0 | `0x56CEA82C` |
| 英語版 | `0x56CE9E3F` |
| 繁体字中国語版 | `0x56CEAB10` |

これ以外の `Launch.exe` の時は何も書き換えません。`mod_log.txt` に `[停止]` と書くだけで、ゲームは普通に動きます。

## 入れ方
`overmase-AI-V~.exe` `overmase-AI-V~anim_cut_musou`の違いは無双発動時にスクリーンアップせずに即無双攻撃します

注意:`overmase-AI-V~anim_cut_musou`は龐徳のムーブセットの無双技「砂暴大征陣」が機能しません馬に乗らず地面に埋まって武器を振ります

1. `dinput8.dll` と `version.ini`と　`overmase-AI-V~.exe` `overmase-AI-V~anim_cut_musou`どちらか好みの方をダウンロードします。
2. 3つともゲームのフォルダ(`Launch.exe` がある所)に置きます。
   例: `C:\Program Files (x86)\Steam\steamapps\common\Dynasty Warriors 8 - Empires\`
3. overmase-AI-V~.exe起動しウィンドウが流れて最後にSuccess!とでていればインストール成功
4. いつもどおりゲームを起動します。

**更新する時:** `dinput8.dll` を入れ替えます。`version.ini` は新しい物に入れ替えるか、自分の ini に新しい区画を書き足してください(書いていない項目はゲーム本来のまま動きます)。

**外し方:** `dinput8.dll` を消してください(`version.ini` も消して構いません)。

同じ場所を書き換える Cheat Engine のスクリプトとは一緒に使わないでください。別の物で既に書き換えられている所を見つけると、DLL はその機能を入れずに、ログに `[中止]` と書きます。

## 機能

全ての機能は `version.ini` で入り切りや調整ができます(説明は日本語と英語で書いてあります)。

### 不具合の対策・クラッシュの守り

| 区画 | 内容 |
|---|---|
| `[Mod]` StealPatch | 枠が足りない時に味方武将が戦場に出てこない不具合の対策 |
| `[Mod]` UniqueModelBoxes | エディット武将・固有武将を同時に固有の見た目で出せる人数を増やす(ゲーム本来 6 → 14) |
| `[Mod]` LoadTableGuard | 武将の読み込みの表(90件)が満杯になって落ちるのを防ぐ |
| `[Mod]` CrashGuard… | ゲーム本来の不具合によるクラッシュの守り(武将の動きの命令のデータが壊れている時の守りを含む) |

### 兵・随伴

| 区画 | 内容 |
|---|---|
| `[Mod]` AllyStrayZako / AllyEscort / EnemyEscort / EnemyLinkedZakoLevel | 味方の野良雑魚兵や武将の随伴を出す・出さない、敵の随伴に付く雑魚兵を減らす |
| `[Mod]` EnemyEscortRewrite / BaseEscortRewrite / RoamingEscortRewrite | 敵の随伴(武将・拠点兵長・遊撃隊長)の兵の種類を書き換える |
| `[EnemyPower]` | 敵の拠点兵長・遊撃隊長・兵が与えるダメージの倍率(武将は対象外) |

### 戦いのバランス・能力

| 区画 | 内容 |
|---|---|
| `[HpScale]` | TypeID ごとの HP の倍率(受けるダメージを減らす / ゲージを伸ばす) |
| `[Affinity]` | 武器の相性で負けている時のスローを弱める、反撃の猶予を無くす、相性負けでも敵を怯ませる(`FlinchAtDisadvantage`) |
| `[Status]` | 武将情報の画面のゲージの最大値(`GaugeMax`)、能力の上限(`StatMax`、最大 30000)、能力の強化の段階(`StatRank`、`1-6` のように範囲も可) |
| `[Stratagem]` | 秘計の再使用までの長さ(自分 / 味方の AI / 敵)、AI の待ち時間・ポイントの回復、効果時間、味方に効く範囲、自分の秘計ゲージの最大値 |
| `[StratagemOverride]` | 秘計の種類ごとのクールタイム・効果時間の倍率(初期設定: 挑発〔TypeID 60〕のクールタイム10倍・効果時間20倍) |

### AI・戦場の動き

| 区画 | 内容 |
|---|---|
| `[AI]` | AI の強さ(味方・敵別々)、空中で受け身を取る確率、受け身の後・飛ばされ続けた時に空中無双・チャージ攻撃・攻撃・ジャンプを出す確率 |
| `[AITarget]` | 武将の AI が近くの敵の武将を狙う、届かない相手を外す、敵の AI がプレイヤーばかり狙うのを減らす |
| `[BaseCapture]` | 画面の外で AI の武将が拠点の耐久力を減らす速さ(味方・敵別々) |
| `[OffscreenMarch]` | 画面の外の武将の進軍の速さ(味方・敵別々)、本陣を守りに戻る時の速さ |
| `[MainCamp]` | 本陣の近くに敵の武将が来たら、その軍の武将に本陣を守らせる(味方・敵別々)。戻る途中で足止めされないようにもできる |
| `[AutoBattle]` | **オートバトル**。F8 で入れる / F10 で切る(パッドのボタンの同時押しも可)。進軍・制圧・本陣の防衛・攻撃・ガード・無双を AI が行う。オートの間は受けるダメージを減らせる |

### 画面

| 区画 | 内容 |
|---|---|
| `[Message]` | 真ん中の帯(「敵本陣へ進軍し…」など)と左の会話の窓の位置 |
| `[Map]` | 地図の切り替えに「非表示」を足す、周辺地図の位置と大きさ |
| `[AllyHP]` | 味方の武将の名前と HP を画面の左端に出す(F9 で入り切り)。一番上に自分の本陣の耐久力も出せる(`ShowCamp`) |
| `[Camera]` | 通常時・ガード時のカメラの距離と角度(FOV) |
| `[RawValue]` | 試験中の数値(上級者向け) |

同梱の `version.ini` の値の多くは、この mod のおすすめの設定です。新しく足した区画(`[AI]` 以降)は、ほとんどがゲーム本来のまま(無効)になっています。説明に書いてあるゲーム本来の値に戻すと、その部分は元どおりになります。

## ログの見方

DLL はゲームのフォルダに次のファイルを書きます。

| ファイル | 中身 |
|---|---|
| `mod_log.txt` | 起動の記録。`[OK] … を入れました` = 機能が入った、`[中止]` = 入れられなかった、`[設定で無効]` = ini で切ってある、`[エラー]` = ini の値が正しくない |
| `mod_status.txt` | 機能ごとの回数など(30秒ごとに更新) |
| `mod_crash.txt` | `Launch.exe` の中で落ちた時だけ書かれる |

## 不具合の報告

Issue に次の物を付けて送ってください。

- ゲームの版(日本語版 / 英語版 / 繁体字中国語版)
- `mod_log.txt`、`mod_status.txt`(あれば `mod_crash.txt` も)
- 使った `version.ini`
- 不具合が起きた時の状況(モード、マップ、戦闘が始まってからの時間など)

## 注意

- 非公式のファン mod です。コーエーテクモゲームスとは関係ありません。
- 書き換えるのはゲームが動いている間のメモリの上だけです。`Launch.exe` やゲームのデータのファイルは変えません。
- 使う時は自己責任でお願いします。使う前にセーブデータのバックアップを取っておくと安心です。
